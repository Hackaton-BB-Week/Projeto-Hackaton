# MVP — Rolê que Rende

Escopo mínimo do hackathon (3 dias). A fonte de verdade das telas.

## Fluxo
Boas-vindas → Pesquisa diagnóstica → Ponto de partida → Hub → (Vila | Jardim | Chat | Ajuda)

## Telas
1. **Boas-vindas / login** — nome + e-mail (local, sem auth real). Tom acolhedor.
2. **Pesquisa** — 5–7 perguntas (frequência, gasto semanal, impacto, tentativas,
   sentimento, gatilho, objetivo). Uma por vez, com progresso. Gera o gasto
   semanal estimado.
3. **Ponto de partida** — estimativa semanal/mensal/anual + mensagem acolhedora.
   Nunca diagnóstico clínico, nunca rótulo.
4. **Hub** — saudação, métricas (sequência, moedas, preservado), acesso à Vila
   (jogo principal), ao Jardim (progresso), missão do dia, Chat e Ajuda.
5. **Vila que Rende (jogo principal)** — ver `GAMIFICACAO.md`.
6. **Jardim de progresso** — planta que cresce com os dias; cálculo do dinheiro
   preservado.
7. **Chat (Rô)** — respostas pré-definidas no MVP; IA real via Edge Function depois.
8. **Ajuda / SOS** — CVV 188, CAPS, Jogadores Anônimos + respiração guiada.

## Fora do escopo (3 dias)
Push notifications, login social real, múltiplas zonas da vila além de Casa+Praça,
IA conversacional livre (fica como "visão de produto" no pitch).
